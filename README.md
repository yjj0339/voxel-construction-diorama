# 筑造之间 · 体素工地沙盘

一个可交互的 Three.js r160 体素微缩建筑工地。场景包含施工机械、工人、塔吊、运输循环、昼夜变化、扬尘与暴雨天气。

## 在线体验

[打开在线沙盘](https://yjj0339.github.io/voxel-construction-diorama/)

使用支持 WebGL 的手机或电脑浏览器即可访问。下载 `index.html` 或 `筑造之间-体素工地沙盘.html` 后，也能在 Chrome 中直接离线打开；两个文件内容相同。

## 操作

手机：

- 单指拖动环视，松手后平滑减速。
- 双指捏合缩放，同向拖动平移；双击画面恢复全景。
- 底部按钮切换暴雨、复位视角、暂停或继续设备、打开设置。
- 设置中可调节速度、扬尘、昼夜循环、画质和闲置环绕；拖动时刻滑杆定格光影。
- 沉浸模式隐藏界面，右上角“显示界面”按钮随时返回。浏览器支持时还可进入全屏。

电脑：拖拽环视、滚轮缩放；`空格` 切换暴雨，`P` 暂停或继续，`H` 沉浸，`R` 复位，方向键环视，`+` / `-` 缩放。

桌面前方三个实体旋钮也可点按，分别调节设备速度、昼夜循环和扬尘强度。双指操作和拖拽不会触发旋钮。设置保存在当前浏览器本地。

## 技术特点

- Three.js r160 完整内嵌，无运行时外部资源请求
- 约 5,900 个实例化静态方块，39 名实例化体素工人
- 自定义 shader 实现扬尘、雨滴、积水、灯光光晕与探照灯束
- 车辆按受约束的单向闭环路线装料、运输和卸料
- 按屏幕宽高比自动取景，适配竖屏、横屏、刘海屏安全区与移动浏览器地址栏变化
- 自动 / 流畅 / 清晰三档画质；自动档根据设备和持续帧率调整渲染分辨率
- 最高 60 FPS 渲染节奏；后台停止渲染，设备暂停时跳过机械和工人更新
- 手机默认降低粒子与阴影开销，实例矩阵每帧只更新一次，状态面板按需刷新
- WebGL 上下文恢复和启动失败重试；失败时提供流畅画质重试入口

以流畅 60 FPS 为优化目标，实际表现取决于设备、浏览器和温度；桌面模拟手机测试不能替代真机测试。

## 构建与验证

源代码位于 `src/`，执行 `node build.cjs` 同时生成两个完整单文件 HTML。构建过程将 Three.js r160、样式及所有业务代码内嵌，无 CDN 或运行时第三方请求。

`node verify-mobile.cjs` 使用 Chromium 的原生触摸事件接口测试手势、旋钮防误触、横竖屏、设置与电脑操作。默认检查本地 `index.html`，可用 `SANDBOX_URL` 指向线上版本。`node audit-collisions.cjs` 检查施工机械与场地的碰撞约束。

验证脚本使用 D 盘运行时，临时目录、浏览器配置及新验证结果保存在 `.verification/`，不会发布到网站。测试结果需结合脚本采样范围解读，不代表所有时间和所有手机的保证。

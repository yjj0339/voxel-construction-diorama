# 筑造之间 · 体素工地沙盘

一个可交互的 Three.js r160 体素微缩建筑工地。场景包含施工机械、工人、塔吊、运输循环、昼夜变化、扬尘与暴雨天气。

## 在线体验

GitHub Pages 发布后可直接用电脑或手机浏览器访问。建议使用最新版 Chrome、Edge 或 Safari，并开启硬件加速。

## 操作

- 拖拽：环视沙盘
- 滚轮或双指缩放：调整距离
- 空格：切换暴雨
- `H`：切换沉浸模式
- `R`：恢复默认视角
- 桌面前方三个实体旋钮：调节设备速度、昼夜循环和扬尘强度

## 技术特点

- Three.js r160 完整内嵌，无运行时外部资源请求
- 约 5,900 个实例化静态方块，39 名实例化体素工人
- 自定义 shader 实现扬尘、雨滴、积水、灯光光晕与探照灯束
- 车辆按受约束的单向闭环路线装料、运输和卸料
- 桌面浏览器测试中日景与暴雨场景均稳定高于 60 FPS

直接打开 `index.html` 即可本地运行。
